This report documents the completed cross-identification of the 179,804 entries in the curated first volume of the Córdoba Durchmusterung (CD), zones −22 through −31, against PPM and GSC. It handles single stars, visually double entries, historical colour annotations and a selected sample of large-amplitude variables, using a global exclusive assignment — SCIP for components containing CD doubles, the Hungarian algorithm otherwise.

The method itself, its literature and the general tool interface are documented in [README.md](README.md); this file covers what is specific to this run: the pipeline, catalog preparation, the constants actually fitted, the results and their validation, and the machine-readable format.

The catalog is **[cd_ppm_gsc.txt](cd_ppm_gsc.txt)**, regenerated on 20 September 2026 with the model below.

## 1. Pipeline

Run from `likelihood`, with a `python` that has NumPy, pandas, SciPy, Astropy and PySCIPOpt available. The completed run used PySCIPOpt 6.2.1 with SCIP 10.0.2.

```sh
# 1. Rebuild the source union from repository catalogs and prepare hypotheses.
#    Required first step in a clean checkout: writes cd_cross/prepared, plus the
#    calibrated tables and the solver checkpoint under cd_cross/results.
python cross_double_likelihood.py --prepare --build-only

# 2. Solve the saved hypotheses; writes cd_ppm_gsc.txt and auxiliary results.
python cross_double_likelihood.py --solve-only

# 3. Check the published records and compare with PPM's CD designations.
python cross_double_likelihood.py --validate

# Optional: also run the frozen-model sensitivity study and shifted-position control.
python cross_double_likelihood.py --sensitivity

# Optional: re-export the fixed-width catalog without repeating the optimization.
python cross_double_likelihood.py --export-only

# Optional: recalibrate and rebuild hypotheses from cached tables, without solving.
python cross_double_likelihood.py --rebuild --build-only
```

`--data` selects a different calibrated-results directory, `--output` the fixed-width catalog, and `--time-limit` the per-component SCIP time limit.

To update the pair model and historical flags while preserving a published calibration and modern union:

```sh
python cross_double_likelihood.py --refresh-flags
```

This reads the cached `cd.csv`, `modern.csv` and `calibration.json` under `--data`, refreshes double/colour and uncertainty flags from the current repository lists, rebuilds hypotheses and components, and solves again. It refuses changed original CD records; those require `--prepare`. The completed run used this route, preserving the existing PPM–GSC merge, variable tags, photometric/astrometric calibration, $Q$ and $p_{single}$. `--rebuild` also refreshes flags, but refits calibration from the prepared source tables. Saved hypotheses with an obsolete model or different historical flags are rejected by `--solve-only`.

## 2. Catalog preparation

CD comes from `cat/cd_vol1_curated.txt`. All original 30-character records are retained, including supplemental and deleted entries. The lists under `cd/` provide the double and colour flags: **1,384 double entries and 739 colour annotations**. The current double lists include 15 additions from the volume-I corrigenda, including one uncertain annotation retained as such in the auxiliary CSV. Deleted and non-stellar entries are preserved without assigned counterparts. Magnitude code 30 denotes a variable and supplies no numerical photometry.

PPM positions are propagated with proper motion and transformed to FK4, equinox and epoch B1875.0. GSC positions are transformed to the same equinox **without** proper-motion correction. Only GSC observations with classification 0 (stellar) or 2 (blend) are retained; classification 3 remains excluded. Multiple surviving observations sharing a GSC identifier are consolidated.

For the PPM–GSC preidentification, PPM is first propagated to each GSC object's effective plate epoch, both remaining in a common J2000 equinox for that step. Where an epoch is absent the preparation uses the documented median fallback, approximately 1979.764, and retains a flag. The preidentification is exclusive and uses a calibrated positional cutoff; ambiguous alternatives are recorded for review.

A merged object retains PPM's name, position and photometry, with GSC as an alias; unmerged GSC objects are then appended. The matching population contains **673,661 objects** in a generous declination halo: all prepared PPM objects, plus GSC objects with magnitude at most 13.5, unknown magnitude, or an accepted variable identification. Known variables stay eligible even when measured fainter than the ordinary cutoff. The same population estimates the background density.

PPM's DM designations are interpreted as CD only for zones −23 through −31; zone −22 belongs to SD and is excluded from the reference comparison. Reference labels do not constrain the matching or impose a target PPM/GSC proportion. **Training-sector labels are used in astrometric calibration**, which must be acknowledged when interpreting the agreement in section 5.

## 3. Model and parameters

Angular quantities are arcseconds, densities per square arcsecond. Principal candidates use **R = 360″ (6′)** around CD. Companions are searched within 2–90″ of each principal, including companions outside the CD search disk. All such dependencies enter the graph before score pruning and component decomposition, ensuring exclusivity across components.

The fitted core scales of the positional kernel (README §3.1) are approximately **13.847 for PPM** and **17.297 for GSC**. These are circular Student scales, **not** Gaussian radial RMS values. A smooth tangent-plane offset was fitted on training sectors but **rejected**, because it did not improve held-out median residuals sufficiently; this run therefore applies no fitted positional shift, though the generic single-star method retains the validation-gated correction for other historical catalogs.

Photometric transformations predict CD magnitude separately by source band. The PPM V relation retains the polynomial from `trig.cpp`:

$$
m_{CD}=-0.157169+1.188316\,V-0.022130\,V^2.
$$

|---|---|---:|
| PPM V | −0.157169, 1.188316, −0.022130 | 0.50 |
| PPM non-V, blank band code | −5.408617, 2.772864, −0.127751 | 0.8333 |
| GSC band 0 | 4.897207, 0.395042 | 0.50 |

| GSC band 4 | 1.069210, 0.868297 | 0.50 |

These GSC codes denote **distinct passbands and must not all be relabelled V**. Fits use robustly clipped least squares, exclude variable neighbourhoods, and reserve every fifth five-degree RA sector for validation. GSC fits use PPM–GSC anchors rather than indiscriminately fitting faint nearest neighbours. Outside training ranges, monotone linear continuation and increased uncertainty replace unrestricted polynomial extrapolation; unsupported populations fall back to position-only evidence.

### Single-counterpart evidence

Let $L(a,p)$ be the robust CD–counterpart likelihood ratio of README §3.1. Its photometric multiplier is

$$
\operatorname{clip}\left[\frac{t_3((m_a-m_p)/s_{ap})}{s_{ap}\,b(m_a)},\ 0.05,\ 20\right],
\qquad s_{ap}=\frac{\sqrt{\sigma_{CD,p}^2+\sigma_{var,p}^2+0.5^2 I_{color}(a)}}{\sqrt3}.
$$

Here $b$ is the smoothed background magnitude density. The table gives base $\sigma_{CD,p}$, an RMS rather than the Student-t scale. PPM V uses **0.50 mag**. The implementation multiplies the calibrated PPM residual RMS by **5/3** (`ppm_cd_sigma_factor`); this also changes the non-V base from 0.50 to 0.8333 mag. GSC dispersions are unchanged. Extrapolation multiplies the applicable RMS by 1.5. Missing photometry is neutral. The normalized density is recomputed when its width changes, including the peak normalization.

### Ordered principal–companion evidence

For a double-marked CD entry, only the **principal** is compared to CD in position and magnitude. There is no CD–companion positional or photometric factor. With $\Delta m=m_c-m_p$ and component separation $s_{pc}$,

$$
H(p,c)=\frac{2k_{pair}g(s_{pc})}{2\pi\mu_{ref}}\,
\frac{(f_{split}*\mathcal N(0,\tau_{pc}^2))(\Delta m)}{f_{split}(0)}.
$$

The separation density is a generalized normal truncated to **2–90″**:

$$
g(r)=\frac{1}{Z}\exp\left[-\frac12\left|\frac{r-44.19}{30}\right|^4\right],
\qquad Z=\int_2^{90}\exp\left[-\frac12\left|\frac{r-44.19}{30}\right|^4\right]dr
=63.85447555''.
$$

The scale 30″ is not a standard deviation. The centre is nearly flat over 30–60″, with smooth declining tails and a hard candidate ceiling of 90″. The constant reference-area denominator uses $\mu_{ref}=44.18584''$.

The independent pair-weight multiplier is **$k_{pair}=1.6770333532$**, equivalent to adding **0.5170263713** to every pair log-score relative to the normalized density alone. It fixes the compensated central density to **0.026263364 arcsec⁻¹**, preserving the reference central score scale while relaxing separation preferences. This multiplier is not part of the normalized density $g$. It changes double-versus-single preference but cancels when comparing two pair hypotheses. Principal astrometry, principal photometry, split-normal contrast, $p_{single}$ and $Q$ are not rescaled. Neither the shape nor this normalization guarantees a fixed number of assigned doubles.

The contrast density is a zero-mode split normal:

$$
f_{split}(x)=\frac{\sqrt{2/\pi}}{\sigma_-+\sigma_+}
\begin{cases}
\exp[-x^2/(2\sigma_-^2)],&x<0,\\
\exp[-x^2/(2\sigma_+^2)],&x\ge0,
\end{cases}
\qquad \sigma_-=0.30,\quad\sigma_+=1.00\ \mathrm{mag}.
$$

Negative contrast means the companion is brighter and is penalized more strongly. The convolution includes independent component photometric and variability errors:

$$\tau_{pc}^2=\sigma_{m,p}^2+\sigma_{m,c}^2+\sigma_{var,p}^2+\sigma_{var,c}^2.$$

These component errors retain their fitted values: 0.30 mag for PPM V and 0.50 mag for the other supported populations, with extrapolation inflation. They are **not** multiplied by the CD–PPM residual factor 5/3. Missing contrast photometry contributes a factor of one.

Allowed ordered source pairs are **PPM/PPM, PPM/GSC and GSC/GSC**; GSC/PPM is excluded. All eligible orientations are evaluated separately. The first exported designation is the principal, preserving PPM preference in mixed pairs.

### Hypothesis weights and optimization

For double-marked entries, singleton and pair weights are respectively

$$W_{a;p}=Qp_{single}L(a,p),\qquad
W_{a;p,c}=Q(1-p_{single})L(a,p)H(p,c)/\rho_a.$$

For ordinary CD entries the singleton weight is $QL(a,p)$. The empty weight is approximated by $1-QF$, where $F$ is the positional search-disk mass. Costs are minus the log weight relative to empty; positive costs are dominated by empty. The prior $p_{single}$ is approximately **0.3651**; $Q$ is fitted from ordinary CD entries for this run. Each CD entry selects one hypothesis, and each modern object can occur at most once. Components with at least one CD double use SCIP; the remaining components use Hungarian assignment.

The factor 2, peak-compensation multiplier, constant reference area and normalization by $f_{split}(0)$ define a provisional score scale. The split-normal widths, separation prior, $p_{single}$ and approximate double search mass are not a fully calibrated background-companion model. The formula models neither blended flux nor a photocentre, and its scores are not posterior probabilities.

## 6. Machine-readable format

### Fixed-width catalog

`cd_ppm_gsc.txt` follows the layout specified in `cat/new_format.txt` of Severin (2018), *Cross-identification between Cordoba Durchmusterung catalog (declinations −22, −23 and −24) and PPMX catalog*, Mendeley Data V1, DOI [10.17632/5wwwtv7c8c.1](https://doi.org/10.17632/5wwwtv7c8c.1), CC BY 4.0.

That dataset applied the layout to zones −22 to −24 against PPMX; the present catalog keeps the same **71 ASCII characters per record** plus a newline, and extends the coverage to zones −22 through −31 against PPM and GSC. The first 30 bytes are identical to `cat/cd_vol1_curated.txt`; ordering and all 179,804 rows are preserved. The A19 identifier fields already accommodate both PPM and GSC designations, so no width change was needed.

| Bytes | Format | Units | Label | Meaning |
|---|---|---|---|---|
| 1–2 | A2 | — | prefix | `CD` |
| 3–5 | I3 | deg | zone | Declination zone |
| 6–10 | I5 | — | num | Number within the zone |
| 11 | A1 | — | suppl | Original supplement/corrigendum marker; `D` denotes deletion |
| 12–15 | F4.1 | mag | mag | Original CD magnitude; 20.0 = nebula, 30.0 = variable |
| 16–17 | I2 | h | RAh | Right ascension, 1875 |
| 18–19 | I2 | min | RAm | Right ascension minutes |
| 20–23 | F4.1 | s | RAs | Right ascension seconds |
| 24 | A1 | — | DE− | Declination sign |
| 25–26 | I2 | deg | DEd | Declination degrees, 1875 |
| 27–30 | F4.1 | arcmin | DEm | Declination arcminutes |
| 31 | A1 | — | dpl | `D` for a visually double entry; otherwise blank |
| 32 | A1 | — | color | `C` for a yellow/red annotation; otherwise blank |
| 33 | A1 | — | type | `0`, `1` or `2` assigned modern counterparts |
| 34–52 | A19 | — | star1 | First designation, left-aligned and space-padded |
| 53–71 | A19 | — | star2 | Second designation, or blanks |

For type 0 both designation fields are blank; type 1 uses only star1. Type 2 is allowed **only** for a double-marked CD entry.

Designations take the forms `PPM 123456` and `GSC 01234-05678`. The principal is reported first and equals the CSV's `astrometric_primary`; a mixed pair always has PPM as principal. Uncertain historical double and colour annotations appear here only as their D/C flags, with explicit uncertainty columns in the CSV.

## 7. Limitations and next research steps

1. PPM reference agreement is partly linked to calibration and says little directly about the GSC-only majority. Inspect discrepancies and seek independent checks before treating associations as settled.
2. GSC lacks proper-motion correction in the historical comparison. Epoch fallback, blends, duplicate observations and an incorrect frozen PPM–GSC merge can all affect results.
3. One circular scale and a broad mixture cannot represent all zone-dependent anisotropy, transcription errors or local historical systematics. The selected anchors do not fully characterize extreme tails.
4. Faint-end selection, band differences and photometric extrapolation remain approximate. The clipped photometric ratio is not a fully specified population or selection likelihood.
5. `p_single`, the separation prior and the pair search mass are provisional. Double/single classification depends on these choices. The ordered principal–companion model represents neither blended flux nor a photocentre. Split-normal widths and pair-score normalization require independent calibration; the non-V PPM broadening is an extension of the V-band setting.
6. GCVS coverage and the positional tagging procedure are incomplete. Uniform phases, other-band scatter proxies and uncertain extrema need star-specific follow-up wherever they influence a decision.
7. Local margins and incremental costs are not globally marginalized posterior probabilities, and the double workflow does not yet recompute a global alternative-solution margin for every association. An empty result may mean insufficient evidence, conflict, exclusion, missing coverage or catalog error.
